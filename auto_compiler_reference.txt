You are redesigning the memory model of a systems programming language that currently uses a Rust-like ownership system with an explicit `Box<T>` type for heap allocation.

Your task is to REMOVE the `Box` concept completely and replace it with implicit heap allocation using escape analysis, similar to Go.

Requirements:

1. Eliminate `Box<T>` from:

   * Type system
   * Syntax
   * Standard library
   * Compiler IR

2. All values should be written as plain value types:

   * `Node` instead of `Box<Node>`
   * No explicit heap wrappers in user code

3. Implement escape analysis in the compiler:

   * If a value does NOT escape its scope → allocate on stack
   * If a value escapes (returned, referenced, captured, or stored externally) → allocate on heap

4. Define escape conditions:

   * Returning a value from a function
   * Returning a reference to a local variable
   * Assigning to a longer-lived variable
   * Capturing in closures
   * Storing in heap-allocated structures

5. Internally:

   * Insert hidden pointer representations when heap allocation is required
   * Automatically manage dereferencing (no explicit `*` or `->` required by user)
   * Preserve ownership semantics (move, borrow if implemented)

6. Recursive types:

   * Automatically treat recursive fields (e.g., `next: Node?`) as heap-backed
   * Prevent infinite-size types via implicit indirection

7. Ensure:

   * No performance regression compared to explicit `Box`
   * Stack allocation remains default and fast
   * Heap allocation is minimized via escape analysis

8. Optional (but recommended):

   * Implement auto-dereferencing
   * Implement lifetime inference or simplified borrow checking
   * Provide debug mode to visualize when heap allocation occurs

9. Output:

   * Updated type system rules
   * Compiler changes (AST + IR + codegen)
   * Memory model specification
   * Example transformations (before vs after)

Goal:
Create a clean, minimal syntax like Go, while preserving Rust-like safety and performance, without exposing heap allocation constructs like `Box`.
