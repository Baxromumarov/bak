# HashMap<K, V> in Bak

`HashMap<K, V>` is the supported hash-map type. The implementation lives in
`src/std/collections/hashmap.bak`; `Map<K, V>` is not part of the stable
language surface.

```bak
package main

import hashmap "std/collections/hashmap"

func main() -> (void) {
    mut var names: hashmap.HashMap<int, string> = hashmap.newHashMap()
    names.insert(1, "Bak")

    switch names.get(1) {
        case Ok(name) { println(name) }
        case Err(e) { println(e) }
    }
}
```

The main methods are `insert`, `get`, `remove`, `containsKey`, `len`, and
`isEmpty`. Lookups and removals return owned values in `Result`; there are no
borrowed map entries in the v0.1 API.

Hashing is supplied by the runtime for supported key types. See
`docs/CORE_LANGUAGE_SPEC.md` for the normative language contract and
`docs/STDLIB_STABLE_V0.1.md` for the compatibility status of the package.
