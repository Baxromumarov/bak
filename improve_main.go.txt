## ✅ Recommended pattern: Command registry (Go-style, but cleaner)

Instead of:


### Do this:

```go
type Command struct {

    "build": buildCommand,
```


* Adding commands becomes trivial
* You can later plug in:

👉 This is how tools like **Docker** and **Git** scale

## Registry

### `internal/cli/registry.go`

```go
type Registry struct {
    commands map[string]Command
}

func NewRegistry() *Registry {
    return &Registry{commands: make(map[string]Command)}
}

func (r *Registry) Register(cmd Command) {
    r.commands[cmd.Name()] = cmd
}

func (r *Registry) Execute(ctx *Context, args []string) error {
    if len(args) == 0 {
        return r.commands["repl"].Run(ctx, nil)
    }

    cmd, ok := r.commands[args[0]]
    if !ok {
        return fmt.Errorf("unknown command: %s", args[0])
    }

    return cmd.Run(ctx, args[1:])
}
```

# ⚙️ 4. COMPILER PIPELINE (CRITICAL REFACTOR)

## This removes duplication across:

* `runFile`
* `runFileVM`
* `buildFile`
* `checkFile`

---

### `internal/pipeline/pipeline.go`

```go
type Pipeline struct {
    Filename string
    Source   string

    AST      *ast.Program
    Module   *compiler.Module
}
```

---

## Stages

### parse.go

```go
func Parse(p *Pipeline) error {
    l := lexer.New(p.Source)
    parser := parser.New(l)

    program := parser.ParseProgram()
    if len(parser.Errors()) > 0 {
        return fmt.Errorf("parse error: %v", parser.Errors())
    }

    p.AST = program
    return nil
}
```

---

### typecheck.go

```go
func Typecheck(p *Pipeline) error {
    tc := typechecker.NewWithPath(p.Filename)
    errs := tc.Check(p.AST)

    if len(errs) > 0 {
        return fmt.Errorf("type errors: %v", errs)
    }

    return nil
}
```

---

### compile.go

```go
func Compile(p *Pipeline) error {
    c := compiler.New()

    module, err := c.Compile(p.AST)
    if err != nil {
        return err
    }

    p.Module = module
    return nil
}
```

---

### run_vm.go

```go
func RunVM(p *Pipeline, ctx *cli.Context) error {
    v := vm.NewWithPermissions(p.Module, ctx.Permissions)
    _, err := v.Run()
    return err
}
```

---

### build_native.go

```go
func BuildNative(p *Pipeline, output string, ctx *cli.Context) error {
    exe, err := native.BuildExecutableWithOptions(p.AST, native.BuildOptions{
        Permissions: ctx.Permissions,
    })
    if err != nil {
        return err
    }

    return os.WriteFile(output, exe, 0755)
}
```
